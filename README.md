# Faramade Michael Ayeni — Academic / Applied AI Portfolio

A research-oriented personal portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Current scope

- Research-first homepage
- TARA research case study
- AcademicGPS case study
- Market Intelligence System architecture case study
- PortfoliAI architecture case study
- TechSphere engineering case study
- About page
- Academic CV PDF
- SEO metadata, robots, and sitemap foundation

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Environment

Copy `.env.example` to `.env.local` and set the public site URL when you know the production domain:

```bash
NEXT_PUBLIC_SITE_URL=https://your-domain.com
```

## Deploy

1. Push this repository to GitHub.
2. Import the repository into Vercel.
3. Add `NEXT_PUBLIC_SITE_URL` after the production domain is known.
4. Deploy.

## Project status language

The site deliberately distinguishes completed/implemented work from system design:

- TARA — Research Project · Completed
- AcademicGPS — Functional MVP · Active Development
- Market Intelligence System — System Design · Pre-Implementation
- PortfoliAI — Product Architecture · Pre-Implementation
- TechSphere — Built & Deployed

This distinction should be preserved as the portfolio evolves.
